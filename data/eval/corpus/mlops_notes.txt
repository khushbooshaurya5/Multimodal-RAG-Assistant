Model deployment checklist. Package the model with its preprocessing code so training-serving skew is avoided. Version the model artefact, the code and the data snapshot together. Expose a health endpoint and log latency percentiles (p50, p95, p99) rather than averages. Monitor input drift by comparing live feature distributions with the training distribution. Roll out with a canary or shadow deployment before switching all traffic. Keep a rollback path to the previous model version.
